## Как запустить

```bash
pip install -r requirements.txt

```

Данные загружаются автоматически по ссылке на репозиторий IBM. Если ссылка недоступна, ноутбук пробует зеркало, а затем локальный файл `Telco-Customer-Churn.csv` рядом с ноутбуком (скачать можно на Kaggle: `blastchar/telco-customer-churn`). Сам файл данных в репозиторий не добавлен.

## Основные выводы

- Отток сосредоточен в первые месяцы обслуживания: среди клиентов с одним месяцем обслуживания ушли 62 %.
- Самая «горячая» группа — оптоволокно (`Fiber optic`) на месячном договоре: отток 54,6 % при 2128 клиентах; на двухлетнем договоре та же оптика теряет 7,2 %.
- Оплата электронным чеком связана с оттоком 45,3 % против 15–19 % у остальных способов.
- У ушедших клиентов месячный платёж выше, причём на длинных договорах разрыв растёт.
- Обрезанная ось и отсутствие подписей на столбчатом графике преувеличивают разницу в 6,8 раза вместо реальных 3 раз (задание 4).
